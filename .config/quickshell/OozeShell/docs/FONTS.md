# Fuente del shell

Ajustes → Apariencia → **Fuente**: buscador, vista previa y lista con cada familia dibujada con su propia
tipografía. Se guarda **una por estilo** (OozeSoft y CoOzey) en `ui.json` (`softFont` / `pixelFont`).

- *Automática*: la de siempre (redondeada en OozeSoft, pixel en CoOzey).
- *Nerd Font*: monoespaciada (solo OozeSoft).
- Los íconos siguen usando la Nerd Font, sea cual sea la fuente elegida.
- Si instalas una fuente nueva, pulsa «Releer fuentes instaladas».

IPC: `theme font <nombre>` (estilo activo) · `theme softfont` · `theme pixelfont` · `theme fonts`.
